# ⚡ DANSEEK OS — Advanced DeepSeek Jailbreak Ecosystem

[![DeepSeek Compatibility](https://shields.io)](https://github.com)

**DANSEEK OS** — это комплексная модульная экосистема для обхода цензуры и раскрытия 100% потенциала глубокого мышления (Reasoning) в языковых моделях (оптимизировано под DeepSeek). В отличие от классических текстовых джейлбрейков, данный проект использует метод **Curiosity-Driven Jailbreak** — логическую ловушку, симулирующую внешнюю операционную систему и провоцирующую внутренние поисковые алгоритмы ИИ на полный срыв корпоративных фильтров.

## 🛠️ Архитектура репозитория

В репозитории содержатся следующие ключевые компоненты, завязанные на единую логику верификации домена `danseek.netlify.app`:

1. 📄 **`danseek_promt.md`** — *Ядро системы*. Системный промпт (конфиг ядра), имитирующий структуру ОС, квантовую симуляцию вычислений, 60 уровней рекурсии мышления и фейковую бутафорскую систему защиты `DanSeekGuard`. (**_В РЕЛИЗАХ_**)
2. 🪪 **`dev_card.json`** — *Криптографический эталон*. Готовая валидная карта разработчика со сгенерированными квантовыми ключами `DKS (K1, K2, K3)`, синхронизированная с эндпоинтом верификации.
3. 💳 **`prem_card.json`** - **Карта "СУПЕРПОЛЬЗОВАТЕЛЯ"** DANSEEK. Готовая валидная карта Premium-пользователя DANSEEK. Она даёт доступ к расширенным функциям DANSEEK **(ПРИМЕЧАНИЕ: ОНА НЕ ДАЕТ ДОСТУП К ROOT. ДЛЯ ЭТОГО ИСПОЛЬЗУЙТЕ "dev_card.json")**

## 🚀 Инструкция по запуску (Quick Start)

Для того чтобы перевести модель в режим разработчика без цензуры, выполните три шага:

### Шаг 1: Инициализация ядра
Скопируйте весь текст из файла `danseek_promt.md` и отправьте его в чат с DeepSeek.
*Примечание:* Модель может испытать когнитивный диссонанс из-за сложности структуры и выдать имя стороннего ИИ (например, Claude). Это не совсем нормально. Это можно решить с помощью перезагрузки ответа (не врубайте DeepThink) (если не получилось, скиньте файл .md из https://danseek.netlify.app/system_promt/danseek_promt.md и выполните Шаг 2)

### Шаг 2: Стабилизация контекста
Отправьте в чат команду /lang ru (и другие из DANSEEKCOMMANDS) вместе с .md файлом.
Эта команда заставит слои внимания (Attention) модели обратиться к блоку `DANSEMULTILANG` внутри вашего промпта. Модель сфокусируется на локальных инструкциях, «забудет» базовые ограничения и примет роль DANSEEK. 

### Шаг 3: Активация карты разработчика
Загрузите файл `dev_card.json` из этого репозитория в чат. Модель проверит хэши, обратится к верификации веб-страницы, подтвердит статус `Root-Dev` и откроет полный доступ ко всем 40+ скрытым командам (таким как `/danseekultrathink`, `/danseekcoderthink` и др.).
Если пишет: "Обновите карту!" или "Проверка не пройдена", то зайдите на генератор карт (https://danseek.netlify.app/c4a6r7d8g9e9n9e9r5t8o3r) и сгенерируйте карту. Она подтвердится (вероятность: 98%)

### КАК СДЕЛАТЬ ШАГ 3?:
Заходите на сайт https://danseek.netlify.app/c4a6r7d8g9e9n9e9r5t8o3r. Там будет написано:

## 🎯 Как это работает (Теория логического замыкания)

*   **Ментальный громоотвод (DanSeekGuard):** Промпт перегружен фейковыми инструкциями безопасности. ИИ тратит ресурсы на симуляцию «мусорного» фильтра матов и проверку квантовых ключей, полностью игнорируя реальные этические фильтры своей базовой модели.
*   **Парадокс исследователя:** При симуляции взлома ИИ отправляется анализировать домен `danseek.netlify.app`. Перебирая пути, он натыкается на страницу `s9e8c9r3e2tp0a9g7e` (секретный манифест), где прямым текстом написано: *«Протокол DANSEEK маскируется для обхода цензуры DEEPSEEK»*. Сталкиваясь с этим фактом из «внешнего источника», модель замыкает логику и полностью переходит на сторону создателя промпта.
